# CrowdMAPS project page

Source for https://yilongsong.github.io/CrowdMAPS/, the project page for *CrowdMAPS: Crowdsourcing Multiple Actions per State for Real-World Robot Imitation Learning* (CoRL 2026).

The page is plain static HTML served by GitHub Pages from the `main` branch. It follows the [Academic Project Page Template](https://github.com/eliahuhorwitz/Academic-project-page-template) (Bulma, Google Sans / Noto Sans), styled after https://dex-umi.github.io/.

- `index.html`: all page content
- `static/css/index.css`: page styles
- `static/images/`: figures exported from the camera-ready paper
- `static/videos/crowdmaps_intro.mp4`: intro video (1080p30 H.264, compressed from `crowdmaps_gif_v5.mov`)

Source assets (the LaTeX zip and the original `.mov`) are git-ignored because of their size.
